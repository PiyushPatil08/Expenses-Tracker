# Expense Tracker - Budget App  

A simple web application to manage your expenses effectively. Track your total budget, expenses, and remaining balance with an intuitive interface.  

---

## Features  

- Set and manage your total budget.  
- Add expenses with titles and amounts.  
- View total expenses and balance updates in real-time.  
- Set reminders when expenses exceed a specific threshold.  
- Responsive design for seamless use on mobile and desktop.  

---

## Technologies Used  

- **HTML**: For structuring the web application.  
- **CSS**: For styling and enhancing the visual appeal.  
- **JavaScript**: For dynamic functionality and user interactions.  
- **Font Awesome**: For icons used in the UI.  
- **Google Fonts**: For improved typography using the "Poppins" font.
